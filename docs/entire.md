# Entire: история работы ИИ-агентов рядом с кодом

Редакция 28.11.2026. Инструмент **по желанию** — проекту он не нужен для сборки.

## Что это

[Entire](https://entire.com) — платформа от Томаса Домке (до августа 2025 — CEO
GitHub), запущена в феврале 2026. Первый продукт — **Checkpoints**: CLI
`entire`, который к каждому коммиту, сделанному с помощью ИИ-агента (Claude
Code, Codex, Cursor, Copilot CLI и др.), сохраняет **контекст**: промпты,
переписку с агентом, рассуждения и список изменённых файлов. Коммит получает
трейлер `Entire-Checkpoint`, а сами данные лежат в отдельных git-ссылках
`refs/entire/checkpoints/…` — в историю ветки ничего не добавляется.

Зачем нам: почти весь код в этом репозитории за ноябрь 2026 написан с агентом.
С чекпоинтами ревьюер (Артём, Матвей) видит не только diff, но и **почему**
сделано именно так.

## ⚠️ Главное: репозиторий публичный

По умолчанию Entire **пушит переписку с агентом на git-remote** вместе с кодом.
Репозиторий `Lilofa/AAvatar_WWW0rk` сейчас **публичный** — переписку прочитает
кто угодно. В наших сессиях обсуждались утёкший ключ стейджинга, найденные
уязвимости и данные оператора. Entire вырезает найденные секреты, но сам пишет,
что это «best effort».

Поэтому — один из двух вариантов:

1. **Только локально** (по умолчанию в нашем скрипте): чекпоинты хранятся у вас
   на компьютере и никуда не уходят —
   `entire configure --local --skip-push-sessions`.
2. **В отдельный приватный репозиторий:**
   `entire configure --local --checkpoint-remote github:<владелец>/<приватный-репо>`.

Пушить чекпоинты в этот публичный репозиторий — **нельзя**.

## Установка и включение

Быстро: из корня репозитория

```bash
./scripts/entire-setup.sh
```

Скрипт ставит CLI (Homebrew, если есть, иначе официальный установщик или
`go install`), выполняет `entire enable` и сразу включает локальный режим.

Вручную:

```bash
brew install --cask entireio/tap/entire
```

```bash
entire version
```

```bash
entire enable
```

```bash
entire configure --local --skip-push-sessions
```

Другие способы (Windows/Scoop, `go install`, установка во время сбоя GitHub) —
[docs.entire.com/installation](https://docs.entire.com/installation).

`entire enable` спрашивает, какие агенты подключить, и ставит свои git-хуки,
сохраняя существующие.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `entire checkpoint list` | чекпоинты в репозитории |
| `entire checkpoint explain <id>` | что внутри: промпты, переписка, файлы |
| `entire checkpoint list --outgoing` | что уйдёт на сервер при следующем push — **проверять перед push** |
| `entire disable` | выключить в этом репозитории |

Дальше — работать с агентом и коммитить как обычно.

## Ограничения

- В облачных сессиях Claude Code (claude.ai/code) установка может быть
  заблокирована проверкой безопасности сессии: Entire встраивает хуки в самого
  агента. Ставьте на своём компьютере.
- Платные функции Entire (свой хостинг репозиториев, Trails, агенты-ревьюеры)
  нам не нужны; Checkpoints работает и без них.
