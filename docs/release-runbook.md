===============================================================
R3. КЛЮЧИ И СБОРКИ (Артём, полдня)
===============================================================
1. Keystore ДО первой release-сборки:
   keytool -genkeypair -v -keystore avatar-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias avatar
   Файл ВНЕ репо (2 защищённых места), пароль у бизнесмена.
   android/key.properties: cp key.properties.example key.properties + заполнить
   (storeFile — абсолютный путь без пробелов). В git не попадёт (gitignore).
2. Сборки (prod-ключи Матвея + DSN Sentry):
   flutter build appbundle --release -t lib/main_sentry.dart --dart-define=SUPABASE_URL=<prod> --dart-define=SUPABASE_ANON_KEY=<prod publishable> --dart-define=SENTRY_DSN=<dsn>
   flutter build apk --release -t lib/main_sentry.dart --dart-define=... (то же)
   flutter build web --release -t lib/main_sentry.dart --dart-define=... (то же)
3. Проверка release-артефакта: установка на живой Android, полный цикл
   в mock-режиме НЕ нужен: только live prod (тестовый заказ R6-0).
4. Версия: pubspec 1.0.0+1; повышение только через +1 к build number.

===============================================================
R4. СТОРЫ (Коля/Артём, день + модерация)
===============================================================
1. Google Play Console ($25 разово, аккаунт компании): приложение →
   AAB из R3; контент-рейтинг 3+; privacy policy URL = страница privacy.html
   задеплоенного team-site; target API в норме; data safety: собираем
   телефон, имя, данные заказов, фото — по docs/legal/privacy-policy.md.
2. RuStore: APK из R3, те же тексты.
3. App Store — решением бизнесмена (нужен Mac/$99); стартуем без него.
4. Тексты листинга (копипаст):
   Название: Аватар — грузчики и переезды
   Короткое: Заказать бригаду грузчиков за 2 минуты: тариф известен до начала работ.
   Описание:
   «Аватар» — приложение службы грузчиков Новосибирска. Оформите заявку за
   2 минуты: адрес с подсказками, время, число грузчиков, транспорт — и сразу
   видите расчёт стоимости построчно. Бригада откликается с указанием ETA,
   диспетчер подтверждает состав, вы следите за этапами работ в реальном
   времени (выехал → на месте → начали → закончили), общаетесь в чате заказа
   с фотографиями и оцениваете работу после завершения — рейтинг грузчиков
   честный, от реальных заказов.
   Возможности: лента доступных заказов для грузчиков; отклик с ETA; этапы и
   штрафы-предупреждения до нажатия; чат бригады с фото; пульт диспетчера:
   одобрение откликов, бригада, замена, форс-закрытие; отзывы и рейтинги;
   реферальная программа для грузчиков.
   Используем силу с умом.
   Что нового (1.0.0): первый публичный релиз: заявки, бригада, этапы, чат,
   отзывы, пульт диспетчера.
5. Скриншоты: 5 штук из release-сборки (лента, визард с расчётом, активный
   заказ с этапами, чат с фото, отзыв); иконка 512 и feature graphic —
   брендовые (#1D5BA6/#F5E326, грузчик в кепке с коробкой).
