ЧТО РЕАЛИЗОВАНО (все 27 методов интерфейса OrdersRepository)
- Auth: send-sms / verify-sms edge + verifyOTP(magiclink, token_hash).
- Лента: realtime orders (status=created) + фильтры + «Мои» через order_takers,
  emptyReason (noOrders/filteredOut/allTaken), мои отклики в карточках.
- Отклик: respond_to_order / cancel_response / watchMyResponse (realtime).
- Этапы: mark_stage / get_stage_availability / submit_delay_reason + realtime
  order_stages; штраф из penalty маркерится как ratingDelta<0 и late.
- Бригада: order_takers realtime, старший (is_lead) с именами из profiles.
- Закрытие: finish_order -> OrderCompletion; watchOrderStatus realtime.
- Отзывы: submit_review НОВОЙ сигнатуры (p_order_id, p_rating, p_text,
  p_target_id=null), getPorterReviews, watchPendingReviewCount.
- Чат заказа: таблица messages + realtime, isMine по author_id.
- Заказчик: createOrder (insert), search-address edge, quote_order RPC,
  watchMyClientOrders, cancelOrder.
- Диспетчер (для сквозного QA): approve/decline_response, assign_lead,
  force_close_order, find_replacement, watchPorterLocations.
- Фото: uploadOrderPhoto в storage-бакет 'orders', возвращает public URL.
- Ошибки: наружу только AppFailure через твой SupabaseErrorMapper
  (+FunctionException от edge-функций).

ОТКРЫТЫЕ ВОПРОСЫ МАТВЕЮ (проговорить в чате команды, зона данных — Матвей):
1. В схеме orders нет колонки-флага force close (forceClosed рисуем false;
   событие приходит только realtime-каналом). Нужна колонка или флаг в jsonb?
2. get_stage_availability не отдаёт feedback_deadline (5 мин после finished) —
   дедлайн обратной связи старшего не рисуется. Добавить ключ в jsonb?
3. В profiles нет fail_count (провалы утренних дедлайнов) — пока 0.
4. quote_order возвращает только numeric: breakdown тарифа собран заглушкой
   (работы + транспорт по тарифу транспорта). Нужна детализация с бэка?
5. createOrder пишет price=0 (NOT NULL): боевой тариф должен считать бэк
   через quote_order при создании или диспетчер при одобрении?

ЗАМЕТКИ
- Время: провод UTC, UI — НСК (UTC+7), конвертация только в mappers.dart.
- ETA-таймаут одобрения отклика = 15 минут (BizRules.etaApprovalTimeout),
  pending старше → ResponseStatus.expired на клиенте (в БД статуса нет).
- Срочность replacement: wire 'urgent' + флаг is_replacement (как у Матвея).
